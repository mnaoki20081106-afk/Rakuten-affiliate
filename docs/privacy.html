1. このツールについて

本ツールは、Threads への投稿を自動化する自己ホスト型のプログラムです。 利用者ご自身の GitHub リポジトリ上で動作し、第三者のサーバーへデータを送信することはありません。 運営者は （あなたの名前・団体名を記入） です。

2. 取得する情報

本ツールは、Threads API を通じて次の情報にアクセスします。

権限取得・利用する内容目的
threads_basicアカウントの識別子（ユーザーID）投稿先のアカウントを特定するため
threads_content_publish投稿の作成・公開設定された時刻に投稿するため
threads_manage_insights投稿のいいね数などの指標反応の良かった投稿を再投稿するため

投稿の本文や商品情報の生成には Anthropic の Claude API を、商品情報の取得には楽天ウェブサービスを利用します。 これらへ送信されるのは、利用者が設定したテーマや商品情報であり、Threads アカウントの認証情報は送信されません。

3. 情報の保存場所

  • アクセストークンおよび API キーは、利用者自身の GitHub リポジトリの GitHub Actions Secrets に暗号化して保存されます。 リポジトリ内のファイルには保存されません。
  • 投稿予定・投稿履歴・紹介済み商品などの記録は、利用者自身のリポジトリ内の JSON ファイルに保存されます。
  • 管理画面で入力した GitHub のアクセストークンは、利用者のブラウザ内 （localStorage / sessionStorage）にのみ保存されます。

4. 第三者への提供

取得した情報を第三者へ販売・提供することはありません。 上記 2. に記載した各サービス（Meta、Anthropic、楽天）への送信は、 本ツールの機能を提供するために必要な範囲に限られます。

5. データの削除

連携の解除は、Threads アプリの設定から本アプリへのアクセス許可を取り消すことで行えます。 保存されたトークンは、GitHub リポジトリの Secrets を削除することで消去できます。 投稿履歴などの記録は、リポジトリ内の該当ファイルを削除してください。
