自動運用

GitHubのPersonal Access Tokenでリポジトリに接続します。
トークンはこのブラウザの中だけに保存され、外部には送信されません。

STEP 1　GitHubのトークンを作る

管理画面がリポジトリを読み書きするための鍵です。下のボタンを押すと、 必要な権限にチェックが入った状態で作成画面が開きます。

  1. 下のボタンから作成画面を開く（GitHubにログインしていなければログイン）
  2. 画面下部の Generate token を押す
  3. 表示された ghp_... をコピーする ※この画面を離れると二度と表示されません

→ トークン作成画面を開く（repo権限つき）

権限は repo だけでOKです。 設定ファイルの読み書きと、APIキーの暗号化保存の両方に使います。

STEP 2　接続する

コピーした ghp_... を貼り付けてください。

接続先のリポジトリ

通常は main のままで構いません。

うまく接続できないとき
  • リポジトリが見つかりませんと出る → オーナー名・リポジトリ名の綴りと、トークンの repo 権限を確認
  • トークンが正しくないと出る → 期限切れの可能性があります。作り直してください
  • fine-grained トークンを使う場合は、対象リポジトリに対して Contents と Secrets を Read and write にしてください
