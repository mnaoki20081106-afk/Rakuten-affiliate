トークンはこのブラウザの中だけに保存され、外部には送信されません。

classic トークンなら repo 権限だけでOKです。 設定ファイルの読み書きと、APIキーの暗号化保存の両方に使います。

トークンの取り方
  1. GitHubの Settings → Developer settings を開く
  2. Personal access tokens → Tokens (classic)
  3. Generate new token (classic) を選ぶ
  4. スコープの repo にチェックを入れて発行 （fine-grained の場合は Contents と Secrets を Read and write に）
  5. 表示された ghp_... をコピーして上に貼り付ける
