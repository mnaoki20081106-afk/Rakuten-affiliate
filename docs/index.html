GitHubのPersonal Access Tokenでリポジトリに接続します。
トークンはこのブラウザの中だけに保存され、外部には送信されません。

classic トークンなら repo 権限だけでOKです。 （設定ファイルの読み書きと、APIキーの暗号化保存の両方に使います）

通常は main のままで構いません。

トークンの取り方
  1. GitHubの Settings → Developer settings → Personal access tokens を開く
  2. Tokens (classic) → Generate new token (classic)
  3. スコープの repo にチェックを入れて発行 （fine-grained の場合は Contents と Secrets を Read and write に）
  4. 表示された ghp_... をコピーして上に貼り付ける
